## Tools I've built

| Repo | What it does | Write-up |
|---|---|---|
| [software-factory](https://github.com/SreekeshOkky/software-factory) | A Docker container of Claude Code agents that takes a Jira ticket to a verified feature: red-green TDD the orchestrator re-runs itself, a reviewer that comments but never approves, a human merge, and a verifier that checks each acceptance criterion in a real browser. | [Project](https://sreekeshokky.in/projects/software-factory/) |
| [regress](https://github.com/SreekeshOkky/regress) | Visual regression between two releases. It seeds both with the same data and diffs screenshots band by band, so a padding shift isn't a failure. | [Post](https://sreekeshokky.in/blog/visual-regression-testing-across-releases/) |
| [secure-hobby](https://github.com/SreekeshOkky/secure-hobby) | A Claude Code plugin that audits Supabase and Vercel hobby apps without changing them: leaked keys, RLS gaps, JWT problems. | [Post](https://sreekeshokky.in/blog/secure-hobby-security-audit-plugin/) |
| [opencode-agent-browser](https://github.com/SreekeshOkky/opencode-agent-browser) | An OpenCode plugin that gives terminal agents a browser, so they can see and debug the apps they build. | [Post](https://sreekeshokky.in/blog/opencode-browser-tools/) |
| [Mottainai](https://github.com/SreekeshOkky/Mottainai) | An AI-guided "do I really need this?" check before you buy, with all data kept in the browser. | [Project](https://sreekeshokky.in/projects/mottainai/) |
| [Nirman](https://github.com/SreekeshOkky/Nirman) | A white-label construction-site ledger for builders, operated through an AGENTS.md playbook. | [Project](https://sreekeshokky.in/projects/nirmanam/) |
